# Teens18 Android App

A native Android app for [teens18.info](https://teens18.info/) WordPress website.

## Features
- Dark/Light mode
- Offline reading (Room database)
- Bookmarks
- Search
- Categories
- HTML ad support (AdSense, custom networks)

## Setup
1. Open in Android Studio
2. Edit \local.properties\ with your SDK path
3. Build and run
